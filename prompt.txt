# ============================================================================
# P) SEED or REVISE the PLAN  (the natural first session; also for outline changes)
# ============================================================================
Read analysis/ICECAPADE_SUBSTRATE_SPEC.md and analysis/facets/PLAN.md.
I want to work on the plan. Take what I give you (conversation, notes, or files in reference/)
and express it as PLAN.md content: premise, arc, the planned-chapter table, plan claims (PL-##),
and open promises (PR-##, each with where it must pay off). Show me the draft before writing.
If PLAN already has content, treat this as a revision: preserve claim IDs where the idea survives,
retire what I've dropped, and list anything the change puts in conflict with already-written text
(divergence queue). If POSITIONING can be seeded/updated from the plan (basis: plan), propose that
too. Commit as an analysis commit; update DASHBOARD + QUESTIONS readiness.

# ============================================================================
# B) INGEST a NEW chapter  (you added a new file to html/)  ← the primary flow
# ============================================================================
Read analysis/ICECAPADE_SUBSTRATE_SPEC.md (esp. §7.1), analysis/DASHBOARD.md, and
analysis/QUESTIONS.md. I've added a NEW chapter to html/. Detect it with
`git status --porcelain -- html/` (new files are untracked; `git diff` alone will NOT show them)
and `git add` it. Read it, then:
1. EXTEND the facets: BOOK_FACTS first (chapter map, roster, dates), then THEMES / WEAKNESSES /
   READER_EXPERIENCE / ARCHITECTURE as warranted — atomic, quote-anchored claims.
2. RECONCILE against PLAN.md: mark promises the chapter pays (status: paid @ anchor); add new
   promises it opens (PR-##); list every divergence from the plan in DASHBOARD's divergence queue
   and tell me — do NOT silently rewrite the plan to match the text or vice versa.
3. If the timeline workbook exists, add the chapter's datable events per block U.
4. Run `python3 tools/anchors.py` — the new chapter must show covered by BOOK_FACTS, 0 stale.
Commit manuscript and analysis SEPARATELY and tag ms-YYYY-MM-DD. Report what you added, what the
chapter paid, and what diverged.

# ============================================================================
# A) INGEST a MODIFIED chapter  (you overwrote an existing html/ file)
# ============================================================================
Read analysis/ICECAPADE_SUBSTRATE_SPEC.md and analysis/DASHBOARD.md.
I've overwritten one or more existing chapter files in html/ (not yet committed).
Find what changed: `git diff --name-only HEAD -- html/`, then
`python3 tools/anchors.py --changed-since HEAD` for the dependent facet anchors; re-verify those
claims (currency workflow, spec §6), update the facets and their verified_against. Re-check PLAN
promises whose paid-anchors sit in the changed chapters. If the timeline workbook exists, run
`python3 tools/timeline_sync.py --since HEAD` and correct flagged rows. Commit manuscript and
analysis SEPARATELY and tag ms-YYYY-MM-DD. Report what went stale and what you changed.

# ============================================================================
# K) CONTINUITY SWEEP  (full Q-CONT audit on demand)
# ============================================================================
Read analysis/facets/PLAN.md, analysis/facets/BOOK_FACTS.md, and the timeline if it exists.
Run a full continuity audit of the draft so far: open promises past their planned payoff point,
plan-vs-text divergences not yet queued, internal contradictions in BOOK_FACTS (names, dates,
ages, geography), and chronology conflicts. Write renders/Continuity_<date>.md with severities;
update the DASHBOARD divergence queue. Findings only — no fixes without my direction.
