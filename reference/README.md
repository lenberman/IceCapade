# reference/ — research & source material

Anything the novel draws on: articles, images, historical notes, maps, outlines-in-progress,
scraps. Input only — nothing here is ground truth (that's `html/`) and nothing here is ever a
quote anchor. Facets may cite files informally as `reference/<file>`.

Tracked in git by default. If something large or churn-heavy lands here (video, big scan sets),
add a line for it to `.gitignore` rather than bloating history.
